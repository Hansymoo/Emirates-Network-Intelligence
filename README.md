# Emirates Network & Fleet Intelligence

Independent portfolio project analyzing publicly available aviation data related to
Emirates operations. **Not affiliated with or endorsed by Emirates.** Built from public
sources only (OpenSky Network, OurAirports); no proprietary or scraped data.

**Key finding:** 2026 regional disruption is visible in the flight data. See
[docs/data_findings.md](docs/data_findings.md) for evidence, sources, and limits.

Status: Phase 3 (database schema) in progress.
